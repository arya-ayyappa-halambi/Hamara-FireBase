The High-Performance Dynamic Schema Database Engine

AegisDB is an enterprise-grade backend-as-a-service (BaaS) that bridges the gap between massive concurrency and uncompromising security. Engineered for modern web architectures, it combines SQLite WAL-mode performance with military-grade two-tier envelope encryption.

Node.js VM SQLite WAL AES-256 GCM Firebase API

High-Concurrency Storage

Leverages SQLite in WAL (Write-Ahead Logging) mode to support highly concurrent read/write operations with zero configuration overhead.

Envelope Encryption

Enterprise-grade DEK/KEK encryption hierarchy. Data is encrypted at rest using AES-256 GCM, securing sensitive fields from unauthorized access.

VM Security Sandbox

Execute complex data validation rules safely. The Node.js VM sandbox allows dynamic rule evaluation without compromising system integrity.

Advanced Authentication

Built-in TOTP multi-factor authentication (MFA) and single-use refresh token family rotation for ironclad identity and session management.

Real-Time Telemetry

Deep observability powered by Prometheus endpoints. Monitor CPU, memory, and query performance in real-time through the Super Admin console.

Multi-Tenant Isolation

Architected for multi-tenancy. Projects operate in strict isolation, ensuring data privacy and preventing cross-contamination of resources.

Production Ready

AegisDB is designed to run anywhere with zero external dependencies.

External Project Code Implementation

1. Client Initialization & Authentication

import Aegis from '@aegis/sdk';

// Initialize SDK pointing to your host server
const aegis = new Aegis({ baseUrl: 'http://localhost:3000' });

// Authenticate developer or project user
await aegis.auth.login('developer@example.com', 'Password123!');
console.log('Authenticated User ID:', aegis.auth.getUser()?.id);

2. Collection Creation & Document CRUD

// 1. Create a dynamic collection
await aegis.db.createCollection('app_orders', 'Customer purchases');

// 2. Insert a document into 'app_orders'
const newOrder = await aegis.db.createDocument('app_orders', {
  customer: 'Alice',
  totalAmount: 149.99,
  status: 'completed',
  items: ['Headphones', 'Keyboard']

// 3. Query documents from 'app_orders'
const orders = await aegis.db.queryDocuments('app_orders');

AI Agent & Developer Context Manual

🧠 Context for AI Agents

When an AI agent (Copilot, Gemini) is instructed to "Migrate this app to use AegisDB" or "Build a frontend for AegisDB", it should understand:

  • Architecture: AegisDB is a RESTful API and WebSocket backend. No proprietary heavy SDKs required; standard fetch() works perfectly.
  • Authentication: Pass your Project API Key in the x-aegis-api-key HTTP header.
  • Security Rule: Do NOT hardcode the API key. Use localStorage, environments, or prompt the user.
  • Data Operations: AegisDB uses JSON Document structures within Collections.
  • File Storage: Supports FormData upload with Magic Byte validation for security.

📡 Standard API Fetch Wrapper

When integrating AegisDB, provide this standard wrapper to your AI so it knows how to make requests securely:

async function aegisFetch(endpoint, method = 'GET', body = null) {
  const apiKey = localStorage.getItem('aegisApiKey'); // Never hardcode!
  if (!apiKey) throw new Error('API Key missing. Please configure it in settings.');

  const headers = { 'x-aegis-api-key': apiKey };
  const options = { method, headers };

  if (body) {
    if (body instanceof FormData) {
      options.body = body; // Browser sets multipart boundary
    } else {
      headers['Content-Type'] = 'application/json';
      options.body = JSON.stringify(body);
    }
  }

  const response = await fetch(`http://localhost:3000${endpoint}`, options);
  const data = await response.json();
  
  if (!response.ok) throw new Error(data.message || 'API Request Failed');
  return data;
}

AegisDB Developer Documentation

1. Initializing the Client

AegisDB can be integrated into any frontend or backend application using our lightweight SDK. Establish a secure connection using your project credentials.

import { AegisDB } from '@aegisdb/sdk';

const db = new AegisDB({
  projectId: 'aegis-prod-1',
  apiKey: 'ak_live_...'
});

2. Real-Time Data Sync

Subscribe to collections or specific documents to receive lightning-fast updates over WebSockets. Our SQLite WAL integration pushes events instantly.

db.collection('users').onSnapshot((snapshot) => {
  console.log('Real-time updates received:', snapshot.docs);
  // Update your UI reactively here
});

3. Node.js VM Security Rules

AegisDB uses a secure V8 isolate (VM sandbox) to evaluate read/write conditions safely without risking server stability.

// Example Security Rule
export default function allowWrite(request, resource) {
  // Only allow if user is authenticated and is the data owner
  return request.auth != null && request.auth.uid === resource.data.ownerId;
}

4. Envelope Encryption (AES-256 GCM)

When storing highly sensitive data, AegisDB automatically encrypts fields at rest using AES-256 GCM based on your schema configuration. Decryption is transparent to the SDK as long as the client is authorized.
