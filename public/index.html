AegisDB v2.5 Enterprise

High-Performance Dynamic Schema Database Engine

AegisDB is an enterprise-grade, high-concurrency database system combining SQLite WAL mode storage, two-tier envelope encryption (DEK/KEK), TOTP multi-factor authentication, single-use refresh token family rotation, Node.js VM security rules sandbox, and full Firebase API compatibility.

Core Features

  • SQLite WAL Mode for high-concurrency reads & writes
  • Envelope Encryption (DEK/KEK) for sensitive fields
  • VM Sandbox Rules for advanced data validation
  • Prometheus Telemetry and Real-Time system stats
  • Multi-Tenant Architecture with strict isolation

Operational Manual

  • Project Management: Create projects to isolate your databases.
  • Authentication: Configure identity providers in the Auth tab.
  • Data & Documents: Manage collections and query documents manually.
  • API Keys: Generate keys in Project Management to authenticate REST requests.
  • Telemetry: View real-time CPU & memory metrics as a Super Admin.
