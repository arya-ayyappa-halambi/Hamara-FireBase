About AegisDB Architecture & Features

Enterprise-grade Firebase-like BaaS platform built on SQLite, RS256 JWKS, and Envelope Encryption.

RS256 JWKS Validation

Asymmetric RSA 2048-bit token signing. Serves dynamic public keys via standard /.well-known/jwks.json for client verification.

Two-Tier Envelope Encryption

Master KEK derived via HKDF-SHA256 wraps 256-bit per-project DEKs. AES-256-GCM field encryption with background key rotation.

Litestream S3 WAL Backup

1-second continuous WAL replication to AWS S3 / MinIO object storage enabling zero-data-loss Point-in-Time Recovery (PITR).

15-Min Lockout Policy

Tracks 5 consecutive failed login attempts per IP:email and enforces an automatic 15-minute HTTP 429 lockout window.

Multi-Driver Storage Engine

Abstracted storage driver interface allowing dynamic switching between Local Disk and AWS S3 / Cloudflare R2 object storage.

Prometheus Metrics (/metrics)

Standard Prometheus exposition format collecting CPU, heap, database latency, active WebSockets, and HTTP request metrics.
